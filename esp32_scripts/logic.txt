# Smart Home Climate Control - Automatic Control Logic

## Temperature Control
- If temperature > 26°C:
  - Turn AC ON (set to 22°C)
  - If room is occupied and air quality is good (MQ135 < 800ppm), open window
  - Turn fan ON
- If temperature between 23-26°C:
  - If room is occupied, turn AC ON (set to 23°C)
  - If room is unoccupied, turn AC OFF
  - Turn fan ON
- If temperature between 19-22°C:
  - Keep AC OFF
  - Keep fan OFF
  - If air quality is poor (MQ135 > 1000ppm), open window
  - Otherwise keep window closed
- If temperature < 19°C:
  - Keep AC OFF
  - Keep fan OFF
  - Keep window closed

## Air Quality Control
- If MQ135 > 1200ppm (poor air quality):
  - Open window (regardless of temperature unless < 19°C)
  - Turn fan ON
- If MQ135 between 800-1200ppm:
  - If temperature allows (>19°C), open window
  - Turn fan ON
- If MQ135 < 800ppm:
  - Control window based on temperature rules
  - Control fan based on temperature rules

## Occupancy Control
- If room occupied:
  - Prioritize comfortable temperature (21-24°C)
  - Ensure good air quality by opening window if needed
- If room unoccupied for more than 10 minutes:
  - Set devices to energy-saving mode:
    - Turn off AC unless temperature > 28°C
    - Turn off fan
    - Control window based on air quality

## System Standby
- When standby mode is activated:
  - Turn off AC 
  - Turn off fan
  - Close window
