# Automated Home Climate Control System

## Team 46:
Kushagra Agrawal - 2024101110
Devshree Vyas - 2024111003
Samarth Rao - 2024111035

This is a smart IoT-based solution to automatically regulate indoor climate using real-time sensor feedback. 
Built using ESP32, MQTT, and a web-based control panel, this system monitors temperature, humidity, CO₂ levels, and occupancy to optimize home comfort and energy usage.
